# Real media-to-notes smoke run

These are unmodified artifacts copied from a clean-environment run, not fixtures
generated by a scripted fake model. Paths inside the logs show the original
temporary locations; copying the artifacts does not change their provenance.

- Input: supplied lecture, seconds **184.35–331.60** (147.25 seconds).
- Local ASR: Whisper `small.en`, CPU int8, batch 4; **13.64 seconds** with cached
  weights. Source recognition differs slightly from the GPU evaluation excerpt.
- Local notes model: `qwen3:4b`; six decisions, including reads, search, two saves
  and model-selected finish. Notes-generation latency: **27.99 seconds** while
  briefly sharing the Ollama server with evaluation (not a speed benchmark).
- Installed from the lockfile into a fresh venv without system packages or torch.

Equivalent command after obtaining the original media:

```bash
uv run lecture-notes run --media /path/to/lecture.webm \
  --start 184.35 --end 331.6 \
  --task "Make study notes on conditional probability and independence." \
  --output runs/media-smoke/notes.md
```

The agent's `run_end` is in `notes.trace.jsonl`; ASR request/result and timing
are in `notes.transcript.asr.trace.jsonl`. No original audio is committed.
