# Gamma-Poisson Bayesian Update

## Key Definitions

- **Poisson Distribution**: Probability mass function for count data: $P(X = x | \lambda) = \frac{\lambda^x e^{-\lambda}}{x!}$
- **Gamma Distribution**: Probability density function: $f(\lambda | \alpha, \beta) = \frac{\beta^\alpha \lambda^{\alpha-1} e^{-\beta \lambda}}{\Gamma(\alpha)}$ (prior distribution for $\lambda$)

## Bayesian Update Derivation

We have $n$ independent Poisson observations $X_1, X_2, ..., X_n$ with parameter $\lambda$ and a prior $\lambda \sim \text{Gamma}(\alpha, \beta)$.

### Joint Likelihood

The joint likelihood of the data given $\lambda$ is:

$$P(X_1, X_2, ..., X_n | \lambda) = \prod_{i=1}^n \frac{\lambda^{X_i} e^{-\lambda}}{X_i!} = \frac{e^{-n\lambda} \lambda^{\sum X_i}}{\prod X_i!}$$

### Posterior Distribution

The posterior distribution is proportional to the product of the likelihood and the prior:

$$P(\lambda | X_1, ..., X_n) \propto \frac{e^{-n\lambda} \lambda^{\sum X_i}}{\prod X_i!} \cdot \frac{\beta^\alpha \lambda^{\alpha-1} e^{-\beta \lambda}}{\Gamma(\alpha)}$$

Simplifying, we get:

$$P(\lambda | X_1, ..., X_n) \propto \lambda^{\sum X_i + \alpha - 1} e^{-(n + \beta)\lambda}$$

### Final Result

This is the kernel of a **Gamma distribution** with parameters:

- $\alpha^* = \alpha + \sum X_i$ (updated shape parameter)
- $\beta^* = \beta + n$ (updated rate parameter)

Thus, the posterior distribution is:

$$P(\lambda | X_1, ..., X_n) \sim \text{Gamma}(\alpha^*, \beta^*) = \text{Gamma}(\alpha + \sum X_i, \beta + n)$$

## Why This Works

The key insight is that by ignoring the normalizing constant (which ensures the distribution integrates to 1), we can identify the posterior as a Gamma distribution with updated parameters. This avoids complex integrations and leverages the conjugacy between Poisson and Gamma distributions.
