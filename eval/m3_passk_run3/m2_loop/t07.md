# Maximum-Likelihood Estimation

## Definition
The maximum-likelihood estimator (MLE) is the value of parameter \(\theta\) that maximizes the likelihood function, defined as:

$$L(\theta) = \prod_{i=1}^n f(x_i | \theta)$$

where \(f(x_i | \theta)\) is the probability density function of the observations \(x_i\) given parameter \(\theta\). The likelihood function represents the probability of observing the data given the parameter.

**Source**: [00:19:48–00:20:18] (Bayes theorem context)

## Why Log Likelihood is Used

The likelihood function is a product of individual densities. Maximizing a product is computationally difficult because:

1. **Product becomes a sum when taking logarithms**:
   - \(\ln L(\theta) = \sum_{i=1}^n \ln f(x_i | \theta)\)
   - This transforms the product into a sum, which is easier to maximize (e.g., using calculus)

**Source**: [00:21:33–00:22:03] (log likelihood explanation)

2. **Numerical stability**:
   - Logarithms convert multiplicative terms into additive terms, avoiding underflow issues when dealing with very small probabilities

**Source**: [00:21:33–00:22:03] (log likelihood explanation)

3. **Differentiability**:
   - The log-likelihood function is typically differentiable, making it easier to find critical points for optimization

**Source**: [00:21:33–00:22:03] (log likelihood explanation)

## Key Example

For a normal distribution with mean \(\mu\) and variance \(\sigma^2\), the likelihood function is:

$$L(\mu, \sigma^2) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi \sigma^2}} e^{-\frac{(x_i - \mu)^2}{2\sigma^2}}$$

Taking the log-likelihood gives:

$$\ln L(\mu, \sigma^2) = -\frac{n}{2} \ln(2\pi \sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^n (x_i - \mu)^2$$

This form is easier to maximize with respect to \(\mu\) and \(\sigma^2\).
