# Predicting Unobserved Variables from Joint Probabilistic Models

## Key Concepts

- **Joint Probabilistic Model**: A joint distribution over all variables in the problem (denoted as $P(x, y, z)$ in the transcript) [00:12:44–00:13:20]
- **Conditional Distribution**: The distribution of one variable given observations of others (e.g., $P(x|y)$) [00:13:38–00:14:25]

## Prediction Process

To predict an unobserved variable $x$ given observed variable $y$:

1. Start with the conditional distribution formula:
   $$P(x|y) = \frac{P(x, y)}{P(y)}$$
   [00:14:25–00:14:59]

2. Express numerator and denominator using the joint distribution over all variables:
   - Numerator: $P(x, y) = \int P(x, y, z) dz$ (integrate over $z$)
   [00:14:25–00:14:59]
   - Denominator: $P(y) = \int P(x, y, z) dz$ (integrate over $z$)
   [00:14:25–00:14:59]

3. Since we have access to the joint distribution $P(x, y, z)$, we can compute these integrals to obtain $P(x|y)$

## Example

Given a joint distribution over three variables $X$, $Y$, and $Z$:
- Observe $Y$
- Predict possible values of $X$

This approach works because we can derive conditional distributions from the joint distribution using the definition of conditional probability and the sum rule (integration over unobserved variables).
