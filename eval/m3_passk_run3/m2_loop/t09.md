# Small-Sample Limitations of Maximum Likelihood Estimation

## Key Definition
Maximum likelihood estimation (MLE) is a method for estimating the parameters of a statistical model given observed data. The MLE is the parameter value that maximizes the likelihood function, which measures how probable the observed data is under a given parameter.

## The Two-Heads Coin Example

**Scenario**: Estimating the probability of heads (p) for a coin with n=2 tosses, both resulting in heads.

**MLE Result**: The MLE for p is 1 (since the observed frequency of heads is 2/2 = 1).

**Problem**: This estimate contradicts common sense. A coin with two heads in a row is unlikely to be biased toward heads (p=1) in reality.

## Why This Exposes Small-Sample Limitations

1. **Small Sample Size**: When n is too small (e.g., n=2), the MLE may not satisfy desirable properties like consistency (the estimate converges to the true parameter as n increases).
2. **Contradiction with Reality**: The MLE estimate of p=1 for two heads is implausible in real-world scenarios, showing that small samples can produce estimates that violate intuitive expectations.
3. **Sample Size Matters**: The lecture notes that with n=1000 trials, the MLE (frequency of heads) would be a good estimate for the true probability (p), but this does not hold for small n.
