# Predicting Unobserved Variables from Joint Probabilistic Models

## Key Definitions
- **Conditional Distribution**: The probability distribution of one variable given the values of other variables. In this lecture, we compute $P(X|Y)$ when observing $Y$ and predicting $X$ (timestamp: [00:13:38–00:14:25]).
- **Probabilistic Model**: A joint distribution over all variables in the problem (e.g., $X$, $Y$, $Z$) (timestamp: [00:14:59–00:15:28]).

## Core Reasoning
To predict $X$ given observed $Y$ (with $Z$ unobserved):
1. Start with the definition: $P(X|Y) = \frac{P(X,Y)}{P(Y)}$
2. Compute numerator: Marginalize $Z$ from joint distribution $P(X,Y,Z)$ to get $P(X,Y)$ (timestamp: [00:14:25–00:14:59])
3. Compute denominator: Marginalize $Z$ from joint distribution $P(X,Y,Z)$ to get $P(Y)$ (timestamp: [0.14:25–00:14:59])
