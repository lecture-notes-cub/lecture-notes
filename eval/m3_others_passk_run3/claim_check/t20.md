# Gamma-Poisson Bayesian Update

## Key Definitions
- **Poisson Distribution**: Probability mass function for count data: $P(X = x | \lambda) = \frac{\lambda^x e^{-\lambda}}{x!}$
- **Gamma Distribution**: Probability density function: $f(\lambda | \alpha, \beta) = \frac{\beta^\alpha \lambda^{\alpha-1} e^{-\beta \lambda}}{\Gamma(\alpha)}$ (prior on $\lambda$)

## Derivation Steps
1. **Joint Likelihood**: For $n$ independent Poisson observations $X_1, ..., X_n$, the joint likelihood is:
   $$P(X_1, ..., X_n | \lambda) = \prod_{i=1}^n \frac{\lambda^{X_i} e^{-\lambda}}{X_i!} = \frac{e^{-n\lambda} \lambda^{\sum X_i}}{\prod X_i!}$$

2. **Posterior with Gamma Prior**: Using a Gamma prior $f(\lambda | \alpha, \beta)$, the posterior is proportional to:
   $$P(\lambda | X_1, ..., X_n) \propto \frac{e^{-n\lambda} \lambda^{\sum X_i}}{\prod X_i!} \cdot \frac{\beta^\alpha \lambda^{\alpha-1} e^{-\beta \lambda}}{\Gamma(\alpha)}$$

3. **Simplification**: The posterior simplifies to:
   $$P(\lambda | X_1, ..., X_n) \propto \lambda^{(\sum X_i + \alpha) - 1} e^{-(n + \beta)\lambda}$$

4. **Posterior Distribution**: This is a Gamma distribution with parameters:
   - $\alpha^* = \alpha + \sum X_i$ (updated shape)
   - $\beta^* = \beta + n$ (updated rate)

## Final Result
The posterior distribution of $\lambda$ is a Gamma distribution with updated parameters:
$$\lambda \sim \text{Gamma}(\alpha^*, \beta^*) = \text{Gamma}(\alpha + \sum X_i, \beta + n)$$

## Example
- **Scenario**: Observing $n=3$ Poisson counts $X_1=2, X_2=1, X_3=3$ with a Gamma prior $\text{Gamma}(\alpha=1, \beta=1)$
- **Posterior**: $\lambda \sim \text{Gamma}(1+6, 1+3) = \text{Gamma}(7, 4)$

## Notes on Uncertainty
- The lecture mentions the derivation is 'very similar to Poisson distribution' but clarifies it's a Gamma distribution.
- The constant multiplier is determined by the normalization condition (integral = 1), so the posterior is exactly a Gamma distribution.
- The derivation avoids full computation by focusing on the form that depends on $\lambda$ and using proportionality.
