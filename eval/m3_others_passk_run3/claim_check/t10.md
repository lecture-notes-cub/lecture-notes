# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta.
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem.

## Core Reasoning

- **Frequentist Approach**: Uses maximum likelihood estimation (MLE) to find a point estimate of theta that maximizes the likelihood of observed data.
- **Bayesian Approach**: Starts with a prior distribution over theta, updates it with observed data via Bayes' theorem to obtain a posterior distribution: 
  \[ P(\theta | X_1, X_n) \propto P(X_1, X_n | \theta) \cdot P(\theta) \]

## Key Differences

| Feature | Frequentist (MLE) | Bayesian |
|---------|-------------------|----------|
| Output | Point estimate (single value) | Full posterior distribution |
| Basis | Maximizes likelihood of data | Combines prior knowledge with data |
| Interpretation | Probability of data given parameter | Probability of parameter given data |

## Example

- **Frequentist**: For a coin flip, MLE estimates theta (probability of heads) as the observed proportion of heads.
- **Bayesian**: With a prior (e.g., uniform distribution), the posterior distribution for theta after n flips is proportional to the likelihood function.
