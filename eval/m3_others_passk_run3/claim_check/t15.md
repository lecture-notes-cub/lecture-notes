# Bayesian Reasoning vs. Boolean Logic: Football Example

## Key Difference

Bayesian reasoning extends Boolean logic by incorporating probabilities instead of strict true/false values. This allows for more nuanced inference from data.

## Boolean Logic Limitation

In Boolean logic:
- Variables are binary (true/false)
- Modus ponens: If A is true and A → B, then B is true
- **Cannot handle inverse cases** (e.g., if B is true and A → B, we cannot conclude A is true)

## Football Example

### Scenario
- **A**: Werder Bremen wins the match
- **B**: Werder fans are celebrating
- **Known**: A → B (If Werder wins, fans celebrate)
- **Observation**: B is true (Fans are celebrating)

### Boolean Logic Failure
- Boolean logic cannot determine A from B and A → B
- Possible outcomes: A true (Werder wins) or A false (Werder loses but fans celebrate for other reasons)

### Bayesian Solution
- Uses joint probability distribution P(A, B)
- Computes posterior probability P(A|B) = P(B|A)P(A) / P(B)
- **Prior**: P(A) = 0.1 (Werder is a weak team)
- **Posterior**: P(A|B) > P(A) (After observing fans celebrating, probability Werder wins increases)

### Why This Matters
- Bayesian reasoning handles uncertainty and updates beliefs with new evidence
- Boolean logic is limited to deterministic relationships
