# Conditional Probability and Independence

## Definition of Conditional Distribution

- **Conditional Distribution of X given Y** ([00:03:04–00:03:35]):
  - For continuous random variables X and Y, the conditional distribution is defined as:
    $$\text{Conditional}(X|Y) = \frac{\text{Joint}(X,Y)}{\text{Marginal}(Y)}$$
  - *Intuition*: Shows how the distribution of X changes when observing Y.

## Independence and Conditional Distributions

- **Independent Random Variables** ([00:04:13–00:05:01]):
  - If X and Y are independent, then $P(X,Y) = P(X) \cdot P(Y)$.
  - **Consequence**: $P(X|Y) = P(X)$, meaning Y contains no information about X.

- **Dependent Random Variables** ([00:05:01–00:05:31]):
  - If X and Y are dependent, observing Y changes the distribution of X.
  - *Example*: If Y provides information about X, then $P(X|Y) \neq P(X)$.

## Key Insight

- **Independence implies no information transfer**: When X and Y are independent, the conditional distribution of X given Y is identical to the marginal distribution of X.
