# Sample Size vs. Parameter Count and Bayesian Updating

## Key Concepts

### Maximum Likelihood Estimation (MLE) and Sample Size

- **Sample Size vs. Parameter Count**: In classical statistics, maximum likelihood estimation (MLE) is justified when the sample size $n$ is not much larger than the parameter dimension $d$ (i.e., $n \gg d$). When $n$ is comparable to $d$, MLE becomes unstable and leads to overfitting.

- **Overfitting in Practice**: When training machine learning models with $n \leq d$, the model fits the training data too closely (overfitting), causing a gap between training and validation errors. When $n \gg d$, the model generalizes well with minimal gap.

### Bayesian Updating with No Observations

- **Posterior Distribution at $n=0$**: When there are no observations ($n=0$), the posterior distribution equals the prior distribution. This is because Bayesian updating requires observations to modify the prior.

- **Example**: For a Bayesian model, if $n=0$, the posterior is the same as the prior (e.g., a uniform distribution for a continuous variable). With one observation, the posterior updates to reflect new information.
