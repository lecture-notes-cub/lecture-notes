# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta. [00:32:13–00:32:53]
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem. [00:32:53–00:33:37]

## Core Reasoning

The lecture explains that Bayesian inference starts with a **prior distribution** reflecting existing knowledge about theta. After observing data $X_1, X_2, ..., X_n$ (independent and identically distributed), it computes the **posterior distribution** $P(\theta | X_1, ..., X_n)$ via Bayes' theorem:

$$P(\theta | X) = \frac{P(X | \theta) \cdot P(\theta)}{P(X)}$$

Where:
- $P(X | \theta)$: Likelihood of data given theta [00:33:37–00:34:13]
- $P(\theta)$: Prior distribution [00:32:53–00:33:37]
- $P(X)$: Normalization constant [00:33:37–00:34:13]

This posterior distribution replaces the point estimate with a full probability distribution over theta.

## Critical Differences

| Aspect | Frequentist Approach | Bayesian Approach |
|--------|----------------------|-------------------|
| **Estimate Type** | Point estimate (e.g., MLE) [00:34:14–00:34:56] | Full posterior distribution [00:34:14–00:34:56] |
| **Foundation** | Data alone [00:32:13–00:32:53] | Prior knowledge + data [00:32:53–00:33:37] |
| **Output** | Single value [00:34:14–00:34:56] | Probability distribution [00:34:14–00:34:56] |

## Example

The lecture mentions that the posterior distribution is derived by multiplying the likelihood (product of $P(X_i | \theta)$) with the prior and renormalizing. This results in a distribution rather than a single point estimate. [00:33:37–00:34:13]
