# Small-Sample Limitations of Maximum Likelihood Estimation

## Key Example: Two-Heads Coin

- **Problem**: Estimate probability of heads (p) from coin tosses using MLE
- **Small sample case (n=2)**: Observed 2 heads → MLE gives **p = 1**
  - [00:31:05–00:31:38] *Contradicts common sense* (e.g., not betting on a coin being two-headed)
- **Why this happens**:
  - MLE properties (e.g., consistency, unbiasedness) require large n
  - [00:28:37–00:29:09] *Small n fails to ensure four properties of MLE*
- **Large sample case (n=1000)**: MLE (frequency of heads) ≈ true p
  - [00:31:38–00:32:11] *Only valid when n is sufficiently large*

## Critical Insight

- **Small-sample MLE flaw**: When n is too small (e.g., n=2), MLE can produce estimates that are *unrealistic* (p=1 for two heads)
- **Why it matters**: MLE is not guaranteed to work well with limited data; common sense and statistical theory require n > 2 for this example
- **Note**: The lecture explicitly states this is a *drawback* of MLE for small samples (not a theoretical flaw)
