# Gamma-Poisson Bayesian Update

## Key Concepts

### Prior Distribution
- **Gamma Prior**: The lecturer mentions using a gamma distribution as a prior for \(\lambda\) (the rate parameter of the Poisson distribution)

### Likelihood Function
- **Poisson Likelihood**: The data \(X_1, X_2, ..., X_n\) follows a Poisson distribution with parameter \(\lambda\)

### Posterior Distribution
- **Gamma Posterior**: After observing data, the posterior distribution for \(\lambda\) is also a gamma distribution with updated parameters

## Derivation

The joint distribution is proportional to:

$$
\prod_{i=1}^n \frac{e^{-\lambda} \lambda^{X_i}}{X_i!} \cdot \frac{\lambda^{a-1} e^{-b\lambda}}{\Gamma(a)}
$$

After simplifying, the posterior distribution for \(\lambda\) is:

$$
\text{Posterior} \propto \lambda^{(a + \sum X_i) - 1} e^{-(b + \sum X_i)\lambda}
$$

This is a gamma distribution with parameters:
- Shape: \(a + \sum X_i\)
- Rate: \(b + \sum X_i\)

## Key Insight

The Bayesian update for \(\lambda\) using a Poisson likelihood and gamma prior results in a posterior that is also gamma-distributed. This is a conjugate prior relationship.
