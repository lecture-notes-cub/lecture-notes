# Alarm Example Study Notes

## Variables

- **T (Thief)**: Binary variable indicating presence of thief (1 = yes, 0 = no) [01:05:57–01:06:37]
- **E (Earthquake)**: Binary variable indicating presence of earthquake (1 = yes, 0 = no) [01:05:57–01:06:37]
- **R (Radio Message)**: Binary variable indicating radio message about earthquake (1 = yes, 0 = no) [01:05:57–01:06:37]
- **A (Alarm)**: Binary variable indicating alarm system activation (1 = yes, 0 = no) [01:05:57–01:06:37]

## Causal Graph

The causal graph shows:

- **E** causes **A** (earthquake can trigger alarm) [01:06:37–01:07:15]
- **T** causes **A** (thief can trigger alarm) [01:06:37–01:07:15]
- **E** causes **R** (earthquake can trigger radio message) [01:06:37–01:07:15]
- **T** does not cause **R** [01:06:37–01:07:15]
- **A** does not cause **T** or **E** [01:06:37–01:07:15]

This graph reflects the inductive bias of the problem where the alarm system is triggered by either a thief or an earthquake, and radio messages are only related to earthquakes.

## Assumptions

1. **Alarm system reliability** (from user guide): If there's a thief, the system will always trigger (100% accuracy) [01:10:10–01:10:52]
2. **False alarms** (from user guide): 10% of the time when there's an earthquake, the system triggers a false alarm [01:10:10–01:10:52]
3. **Earthquake frequency**: In Bremen, small earthquakes happen once per 100 days [01:08:20–01:08:55]
4. **Thief frequency**: On average, 2 flats are robbed per 10,000 in Bremen per day [01:08:20–01:08:55]
5. **Radio message behavior**:
   - If no earthquake, radio will not send message (0) [01:09:27–01:10:09]
   - If earthquake, radio may or may not send message (50% probability) [01:09:27–01:10:09]

## Example Scenario

The lecturer describes receiving an SMS message (A=1) and then hearing a radio message (R=1) about a small earthquake (E=1). The goal is to update beliefs about whether there was a thief (T) or earthquake (E) after this information.

**Key Insight**: The causal graph helps simplify the joint distribution by identifying direct causes and dependencies. The conditional probabilities are derived from real-world data and the user guide of the alarm system.
