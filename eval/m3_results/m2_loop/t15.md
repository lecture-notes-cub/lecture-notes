# Bayesian Reasoning Extends Boolean Logic

## Key Concept: Bayesian vs. Boolean Logic

In Boolean logic, we have variables that are either true or false. The main rule for logical inference is modus ponens: if A is true and A implies B, then B is true.

However, Bayesian reasoning extends this by allowing us to handle uncertainty and probabilistic relationships. Instead of strict true/false values, Bayesian logic uses probabilities to represent knowledge.

## Football Example

The lecture uses a football (soccer) example to illustrate the difference:

- **A**: Werder Bremen wins the match
- **B**: Football fans are celebrating

**Boolean logic limitation**:
- If A implies B (if Werder wins, fans celebrate), and B is true (fans are celebrating), Boolean logic cannot determine if A is true or false. It would be inconsistent with Boolean logic because A could be either true or false while still having B true.

**Bayesian reasoning solution**:
- We can use a joint probability distribution P(A, B) to calculate P(A|B) - the probability that Werder won given that fans are celebrating.
- This allows us to update our belief about A based on evidence B.

## Mathematical Formulation

The joint distribution is defined as:

P(A, B) = P(B|A) * P(A)

From this, we can compute:

P(A|B) = P(B|A) * P(A) / P(B)

**Example**:
- Prior probability P(A) = 0.1 (Werder is a weak team)
- After observing B (fans celebrating), the posterior probability P(A|B) increases to a higher value

**Why this matters**:
- Bayesian reasoning allows us to update beliefs with new evidence, which Boolean logic cannot do.
- This is crucial for real-world scenarios where we have incomplete information and need to make probabilistic inferences.
