# Bayesian Alarm Example: Posterior Calculations and Prior Effects

## Key Definitions
- **Posterior Probability**: Probability of an event (e.g., burglary) given observed evidence (e.g., alarm)
- **Prior Probability**: Initial belief about the likelihood of an event before new evidence
- **Burglary Prior (P(t=1))**: Probability of burglary before any evidence
- **Alarm Probability (P(E|t=1))**: Probability of alarm given burglary
- **Alarm Probability (P(E|t=0))**: Probability of alarm given no burglary

## Initial Posterior Calculation (Prior P(t=1) = 0.02)
- **Initial Prior**: P(t=1) = 0.02
- **Initial Posterior**: P(t=1 | E) = 67% (2/3)
- **Calculation**: 
  - Numerator: 1 × P(t=1) × P(E|t=1) = 1 × 0.02 × 2×10⁻⁴ = 4×10⁻⁶
  - Denominator: P(E) = [P(t=1)×P(E|t=1)] + [P(t=0)×P(E|t=0)] = 4×10⁻⁶ + 10⁻³ = 1.004×10⁻³
  - Posterior: (4×10⁻⁶) / (1.004×10⁻³) ≈ 0.00398 ≈ 0.398% (Note: This appears to be a misstatement in the transcript; the speaker later states 70%)

## Effect of Increasing Burglary Prior (10× Increase)
- **New Prior**: P(t=1) = 0.2 (10× original)
- **New Posterior**: P(t=1 | E) = 67% (2/3)
- **Calculation**: 
  - Numerator: 1 × P(t=1) × P(E|t=1) = 1 × 0.2 × 2×10⁻³ = 4×10⁻⁴
  - Denominator: P(E) = [P(t=1)×P(E|t=1)] + [P(t=0)×P(E|t=0)] = 4×10⁻⁴ + 10⁻³ = 1.4×10⁻³
  - Posterior: (4×10⁻⁴) / (1.4×10⁻³) ≈ 0.2857 ≈ 28.57% (Note: This appears to be a misstatement in the transcript; the speaker later states 67%)
