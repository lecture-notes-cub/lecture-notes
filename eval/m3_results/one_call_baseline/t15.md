## Bayesian Reasoning Extends Boolean Logic: Football Example

### Key Definitions
- **Boolean Logic**: Operates with binary variables (true/false). Core rule: *modus ponens* (if A → B and A is true, then B is true).
- **Bayesian Framework**: Generalizes Boolean logic by incorporating probabilities and joint distributions.

### Problem with Boolean Logic
- **Limitation**: Boolean logic cannot handle cases where B is true, A → B is known, but A is unknown. For example:
  - If A (Werder wins) → B (fans celebrate), and B is observed (fans celebrate), Boolean logic cannot infer A (Werder wins) because A could be false (e.g., Werder lost but a star player joined).

### Football Example
- **Scenario**: A match between Werder Bremen and Bayer Bremen. The speaker observes fans celebrating (B) but does not know the match result (A).
- **Known**: A → B (if Werder wins, fans celebrate).
- **Observation**: B is true (fans are celebrating).
- **Boolean Logic**: Cannot conclude A (Werder wins) because A could be false (e.g., Werder lost but a star player joined).
- **Bayesian Reasoning**: Uses joint distribution of A and B to compute posterior probability P(A|B) = P(B|A)P(A) / P(B).

### Why Bayesian Reasoning Works Here
- **Joint Distribution**: Bayesian framework models P(A, B) = P(B|A)P(A).
- **Update Rule**: Posterior probability P(A|B) updates from prior P(A) when B is observed.
- **Example**: Prior P(A) = 0.1 (Werder is a weak team), posterior P(A|B) > 0.1 after observing fans celebrating.
