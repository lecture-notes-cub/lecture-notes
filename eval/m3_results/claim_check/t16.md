# Alarm Example Study Notes

## Variables
- **T** (Thief): Binary variable (1 = thief present, 0 = no thief)
- **E** (Earthquake): Binary variable (1 = small earthquake, 0 = no earthquake)
- **R** (Radio message): Binary variable (1 = radio announces earthquake, 0 = no radio message)
- **A** (Alarm): Binary variable (1 = SMS alarm triggered, 0 = no SMS alarm)

## Causal Graph

The causal graph shows:
- **T** and **E** are independent causes of **A**
- **E** is the cause of **R**
- **R** does not cause **A**

This graph reflects the inductive bias of the problem (as stated at [01:07:15–01:07:47])

## Assumptions
1. **Alarm system**:
   - If there's a thief, it always triggers (100% guarantee) ([01:10:10–01:10:52])
   - False alarms occur in 10% of cases when there's an earthquake ([01:10:10–01:10:52])

2. **Earthquake probability**:
   - Small earthquakes happen once per 100 days in Bremen ([01:08:20–01:08:55])

3. **Thief probability**:
   - On average, 2 flats are robbed per 10,000 in Bremen ([01:08:20–01:08:55])

4. **Radio message probability**:
   - If no earthquake, radio never announces (0 probability) ([01:08:55–01:09:25])
   - If earthquake, radio announces with 50% probability ([01:08:55–01:09:25])

## Example Scenario

At [01:04:50–01:05:21], the lecturer receives an SMS alarm (A=1) and later hears a radio message (R=1) about a small earthquake (E=1). The lecturer updates beliefs about whether there was a thief (T) based on this information.
