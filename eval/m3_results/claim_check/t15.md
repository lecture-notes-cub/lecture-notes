# Bayesian Reasoning Extends Boolean Logic

## Key Difference: Boolean vs. Bayesian Logic

In Boolean logic:
- Variables are binary: true/false
- Inference rule: **modus ponens**
  - If A is true and A → B, then B is true
- Cannot handle inverse cases: If A → B and B is true, cannot conclude A

In Bayesian reasoning:
- Variables represent probabilities
- Uses joint distributions to update beliefs
- Allows inference in cases where Boolean logic fails

## Football Example: Why Bayesian Logic Works Here

### Scenario
- Let A = "Werder Bremen wins the match"
- Let B = "Werder fans are celebrating"
- Known: A → B (If Werder wins, fans celebrate)
- Observation: B is true (Fans are celebrating)

### Boolean Logic Limitation
- Boolean logic cannot conclude A from A → B and B
- Possible scenarios: A true (Werder wins) or A false (Werder loses but fans celebrate for other reasons)

### Bayesian Update
- Prior probability: P(A) = 0.1 (as stated in the example, Werder is a weak team)
- Joint distribution: P(A, B) = P(B|A) * P(A)
- Posterior probability: P(A|B) = P(B|A) * P(A) / P(B)
- After observing B, P(A|B) > P(A) (Werder is more likely to have won)

### Why This Matters
- Bayesian logic handles uncertainty and updates beliefs with new evidence
- Boolean logic is too rigid for real-world scenarios where multiple causes can produce the same effect
