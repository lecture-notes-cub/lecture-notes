# Maximum-Likelihood Estimation

## Definition
The maximum-likelihood estimator (MLE) is the value of parameter $\theta$ that maximizes the likelihood function:

$$\mathcal{L}(\theta) = \prod_{i=1}^{n} p(x_i | \theta)$$

where $x_i$ are independent and identically distributed (i.i.d.) observations from a distribution with unknown parameter $\theta$.

## Why Log Likelihood?

The likelihood function is a product of probabilities. Taking the logarithm converts the product into a sum, which is easier to maximize:

$$\ell(\theta) = \log \mathcal{L}(\theta) = \sum_{i=1}^{n} \log p(x_i | \theta)$$

This is because:
- **Products become sums** (logarithmic property)

## Key Clarifications from Lecture

- The likelihood function is treated as a function of $\theta$ (not the observations $x_i$), which are fixed.
- The likelihood function is **not** a probability distribution or density function.
- The lecture emphasizes that switching to log likelihood is a practical step to handle the maximization problem.

> [00:21:33–00:22:03] *So, pay attention that we treat this function not as a function of x's, because x's are null, but as a function of theta. And as a function of theta, this is not a distribution, this is not a probability density function, this is a logarithmic function.*
