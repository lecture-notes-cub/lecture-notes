# Asymptotic Properties of Maximum-Likelihood Estimators

## Key Asymptotic Properties

### 1. Asymptotic Unbiasedness

- **Definition**: As $n \to \infty$, the maximum likelihood estimator $\hat{\theta}_{ML}$ satisfies $E[\hat{\theta}_{ML}] \to \theta_0$ (true parameter value).
- **Citation**: [00:22:53–00:23:38] *This means that $\theta_{ML}$ is a random variable, right? And if it's random variable, we can ask ourselves what would be its expectation and what would be its variance, for example. And we can prove that its expectation is asymptotically unbiased. So it equals the true value of our unknown parameter $\theta$ when $n$ is sufficiently large.*

### 2. Consistency

- **Definition**: As $n \to \infty$, $\hat{\theta}_{ML} \to \theta_0$ in probability (converges to the true parameter value).
- **Citation**: [00:24:25–00:25:07] *if the number of observations $n$ goes to infinity, then we can easily prove... that our maximum likelihood estimate converges to the true value when $n$ goes to infinity. And this is, this property is known as consistency.*

### 3. Asymptotic Normality

- **Definition**: For large $n$, $\sqrt{n}(\hat{\theta}_{ML} - \theta_0) \xrightarrow{d} N(0, I^{-1}(\theta_0))$, where $I(\theta_0)$ is the Fisher information matrix.
- **Citation**: [00:25:07–00:26:16] *this is a random variable but it has almost a normal distribution with the mean of course the true value this follows from the property number one and with variance that looks like this so this is $n$ times so-called feature information matrix inverse* (Note: 'feature' likely a typo for 'Fisher')

### 4. Asymptotic Efficiency

- **Definition**: The maximum likelihood estimator achieves the Cramér-Rao lower bound for variance, meaning it has the smallest possible variance among unbiased estimators.
- **Citation**: [00:26:23–00:27:59] *it appears that maximum likelihood estimate has the smallest possible variance. So it has exactly this lower bound for the variance. So no other unbiased estimate can have smaller variance that maximum likelihood estimator has.*

## Clarifications and Notes

- **Fisher Information Matrix**: The inverse of the Fisher information matrix $I^{-1}(\theta_0)$ gives the asymptotic variance of $\hat{\theta}_{ML}$.
- **Cramér-Rao Bound**: The transcript mentions 'Raul Karamer bound' and 'Raul Karamer inequality', which are misspellings of 'Cramér-Rao bound' and 'Cramér-Rao inequality'. This bound states that among all unbiased estimators, the maximum likelihood estimator achieves the smallest possible variance.
- **Unclear Speech**: The phrase 'feature information matrix' is likely a typo for 'Fisher information matrix' (common in statistics). The transcript mentions 'fusion information matrix' which is also a misspelling of 'Fisher information matrix'.
- **Key Example**: The asymptotic normality of $\hat{\theta}_{ML}$ allows for constructing confidence intervals and hypothesis tests.

## Summary

The maximum likelihood estimator has four key asymptotic properties: asymptotic unbiasedness, consistency, asymptotic normality, and asymptotic efficiency (achieving the Cramér-Rao lower bound). These properties hold under regularity conditions and are fundamental to statistical inference.
