# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta.
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem.

## Core Reasoning

- **Frequentist Approach**: Uses maximum likelihood estimation (MLE) to find a point estimate of theta that maximizes the likelihood of observed data.
- **Bayesian Approach**: Starts with a prior distribution over theta, updates it with observed data (X1, Xn) to form a posterior distribution via Bayes' theorem:
  
  $$P(\theta | X_1, X_n) = \frac{P(X_1, X_n | \theta) P(\theta)}{P(X_1, X_n)}$$

- **Posterior Distribution**: The result of Bayesian inference is a probability distribution over theta, not a single point estimate.

## Key Differences

| Feature | Frequentist (MLE) | Bayesian |
|---------|-------------------|----------|
| Output | Point estimate | Full distribution |
| Basis | Likelihood of data | Prior + likelihood |
| Interpretation | Parameter is fixed | Parameter is random |

## Example

- **Frequentist**: If we observe data X1, Xn, MLE finds theta that maximizes $P(X_1, X_n | \theta)$.
- **Bayesian**: With prior $P(\theta)$, posterior is $P(\theta | X_1, X_n) \propto P(X_1, X_n | \theta) P(\theta)$.
