# Maximum-Likelihood Estimation

## Key Definitions
- **Likelihood Function**: For observations $x_1, \dots, x_n$ i.i.d. from a distribution with unknown parameter $\theta$, the likelihood function is:
  $$\mathcal{L}(\theta) = \prod_{i=1}^n f(x_i; \theta)$$
  where $f$ is the probability density function (PDF) of the distribution.
  [00:21:33–00:22:03]

## Why Log-Likelihood?
- **Problem**: Maximizing the product $\mathcal{L}(\theta)$ is numerically unstable and computationally difficult.
- **Solution**: Take the logarithm to convert the product into a sum:
  $$\ell(\theta) = \log \mathcal{L}(\theta) = \sum_{i=1}^n \log f(x_i; \theta)$$
  This simplifies maximization (sums are easier to handle than products).
- **Key Insight**: The log-likelihood is maximized at the same $\theta$ as the likelihood function (since $\log$ is a monotonic transformation).
  [00:21:33–00:22:03]

## Example
- **Simple Case**: For a normal distribution $N(\mu, \sigma^2)$, the MLE for $\mu$ is $\bar{x}$ (sample mean), derived by maximizing the log-likelihood.
  [00:21:33–00:22:03]

## Clarifications
- The likelihood function is treated as a function of $\theta$ (not $x_i$), as $x_i$ are fixed observations.
