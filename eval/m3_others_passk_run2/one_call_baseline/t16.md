## Alarm System Example: Variables, Causal Graph, and Probabilities

### Variables

- **T** (Thief): Binary variable. 1 = thief present, 0 = no thief.
- **E** (Earthquake): Binary variable. 1 = small earthquake, 0 = no earthquake.
- **R** (Radio message): Binary variable. 1 = radio announces small earthquake, 0 = no radio message.
- **A** (Alarm): Binary variable. 1 = SMS alarm triggered, 0 = no SMS alarm.

> **Note**: The ASR uses "ARM" (likely a typo for "alarm") and "R" for radio message. The lecture clarifies that "R" is the radio message about earthquakes.

### Causal Graph

The causal graph is defined as:

- **T** and **E** are independent causes of **A**.
- **E** is the sole cause of **R**.

This graph reflects the inductive bias of the problem and simplifies the joint distribution decomposition.

> **Source**: [01:07:15–01:07:47] "So this is my causal graph. I try to understand what may cause what. So my alarm system may work only because of either thief or earthquake. So then I have this causal dependency and radio message about earthquakes may be caused only by the earthquake."

### Assumptions

1. **Independence of T and E**: The presence of a thief and earthquake are independent events.
2. **Causal structure**: 
   - **A** is caused by **T** and **E** (thief or earthquake).
   - **R** is caused only by **E** (earthquake).
3. **System behavior**:
   - If there is a thief, the alarm system always triggers (100% guarantee).
   - False alarms occur in 10% of cases when there is an earthquake (no thief).

> **Source**: [01:07:15–01:07:47] and [01:08:55–01:09:25]

### Example Scenario

The lecture uses the following scenario:

- The speaker receives an SMS alarm (**A=1**).
- Then hears a radio message (**R=1**) that there was a small earthquake in Bremen.
- The speaker updates beliefs about whether there was a thief (**T**) or earthquake (**E**).

> **Source**: [01:04:50–01:05:21] and [01:05:21–01:05:57]

### Key Definitions

- **False alarm**: When the system triggers without a thief (i.e., **A=1** with **T=0**).
- **System guarantee**: If there is a thief, the system always triggers (100% guarantee).
- **Earthquake impact**: Small earthquakes cause 10% false alarms (no thief).

> **Source**: [01:04:18–01:04:50] and [01:10:10–01:10:52]
