# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta. [00:32:53–00:33:37]
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem. [00:32:53–00:33:37]

## Core Reasoning

- **Frequentist Approach**: Uses maximum likelihood estimation (MLE) to find a point estimate of theta that maximizes the likelihood of observed data. [00:32:53–00:33:37]
- **Bayesian Approach**: Starts with a prior distribution over theta, updates it with observed data via Bayes' theorem to obtain a posterior distribution: 
  \[ P(\theta | X_1, X_n) \propto P(X_1, X_n | \theta) \cdot P(\theta) \] [00:33:37–00:34:13]

## Key Differences

| Feature | Frequentist (MLE) | Bayesian |
|---------|-------------------|----------|
| Output | Point estimate (single value) | Full posterior distribution | [00:34:14–00:34:56]
| Basis | Maximizes likelihood of data | Combines prior knowledge with data | [00:32:53–00:33:37]
| Interpretation | Probability of data given parameter | Probability of parameter given data | [00:34:14–00:34:56]

## Example

- **Frequentist**: For a coin flip, MLE estimates theta (probability of heads) as the observed proportion of heads. [00:34:14–00:34:56]
- **Bayesian**: With a prior (e.g., Beta(1,1) for uniform), the posterior distribution for theta after n flips is Beta(1 + number of heads, 1 + number of tails). [00:34:14–00:34:56]
