# Predicting Unobserved Variables from Joint Probabilistic Models

## Key Definitions
- **Conditional Distribution**: The probability distribution of one variable given the values of other variables. In this lecture, we compute $P(X|Y)$ when observing $Y$ and predicting $X$ (e.g., $Y = y_0$).
- **Probabilistic Model**: A joint distribution over all variables in the problem (e.g., $X$, $Y$, $Z$).

## Core Reasoning
To predict $X$ given observed $Y$ (with $Z$ unobserved):
1. Start with the definition: $P(X|Y) = \frac{P(X,Y)}{P(Y)}$
2. Compute numerator: Marginalize $Z$ from joint distribution $P(X,Y,Z)$ to get $P(X,Y)$
3. Compute denominator: Marginalize $Z$ from joint distribution $P(X,Y,Z)$ to get $P(Y)$

## Example
Given a joint distribution over $X$, $Y$, $Z$:
- Observe $Y = y_0$ (e.g., $Y$ is discrete)
- Predict possible values of $X$ using $P(X|Y) = \frac{P(X,Y)}{P(Y)}$
