## Bayesian Reasoning Extends Boolean Logic: Football Example

### Key Definitions
- **Boolean Logic**: Operates with binary variables (true/false). Core rule: *modus ponens* (if A → B and A is true, then B is true).
- **Bayesian Framework**: Generalizes Boolean logic using probabilities (e.g., P(A|B) instead of Boolean truth values).

### Problem with Boolean Logic
- **Limitation**: Boolean logic cannot handle cases where A → B is true, B is observed, but A is unknown. For example:
  - If A (Werder wins) → B (fans celebrate), and B is true (fans celebrate), Boolean logic cannot infer A (Werder wins) because A could be false (e.g., Werder lost but a star player joined).

### Football Example
- **Scenario**: 
  - A = Werder wins the match
  - B = Fans celebrate (e.g., waving Werder flags)
  - Known: A → B (if Werder wins, fans celebrate)
  - Observation: B is true (fans are celebrating)

- **Boolean Logic Failure**:
  - Cannot conclude A is true (A could be false, e.g., Werder lost but a star player joined, so fans still celebrate)

- **Bayesian Solution**:
  - Use joint distribution P(A, B) = P(B|A)P(A)
  - Compute posterior probability P(A|B) = P(B|A)P(A) / P(B)
  - Update prior probability P(A) → posterior probability P(A|B)

### Example Calculation
- **Prior**: P(A) = 0.1 (Werder is a weak team)
- **Observation**: B is true (fans celebrate)
- **Posterior**: P(A|B) > P(A) (likely higher, e.g., 0.5–0.7)

### Why Bayesian Works Here
- **Common Sense**: Fans celebrating likely indicates Werder won (but not 100% certain)
- **Bayesian Update**: Incorporates new evidence (B) to refine probability of A
