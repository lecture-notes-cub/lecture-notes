## Predicting Unobserved Variables from Joint Probabilistic Models

### Key Concepts

- **Joint Distribution**: A probabilistic model is defined as a joint distribution over all variables in the problem.
- **Conditional Prediction**: When predicting an unobserved variable $X$ given an observed variable $Y$, we compute $P(X | Y)$.

### Derivation Process

1. **Problem Setup**:
   - Given a joint distribution $P(X, Y, Z)$
   - Observe $Y$; want to predict $X$ (ignore $Z$)

2. **Conditional Distribution Formula**:
   $$
   P(X | Y) = \frac{P(X, Y)}{P(Y)}
   $$

3. **Computing Numerator and Denominator**:
   - Numerator: $P(X, Y) = \int P(X, Y, Z) dZ$ (integrate over $Z$)
   - Denominator: $P(Y) = \int P(X, Y, Z) dX dZ$ (integrate over $X$ and $Z$)

4. **Result**:
   - With access to the joint distribution $P(X, Y, Z)$, we can compute $P(X | Y)$ using the above integrals.
