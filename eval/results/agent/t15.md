# Bayesian Reasoning Extends Boolean Logic

## Key Concept
Bayesian reasoning extends classical Boolean logic by incorporating probabilities and updating beliefs based on new evidence. This allows for more nuanced conclusions than Boolean logic, which only handles true/false values.

## Football Example

### Scenario
- **A**: Werder Bremen wins the match
- **B**: Football fans are celebrating

### Known Information
- If Werder wins (A), then fans will celebrate (B) → A → B
- Fans are celebrating (B is true)
- Prior probability of A: 0.1 (Werder is a weaker team)

### Bayesian Update
1. **Prior**: P(A) = 0.1
2. **Likelihood**: P(B|A) = 1 (if Werder wins, fans celebrate)
3. **Joint Distribution**: P(A,B) = P(B|A) × P(A) = 1 × 0.1 = 0.1
4. **Posterior**: P(A|B) = P(B|A) × P(A) / P(B)

### Interpretation
- After observing fans celebrating (B), the posterior probability P(A|B) increases from 0.1 to a higher value (likely > 0.5)
- This shows that Bayesian reasoning can update beliefs to conclude Werder likely won, whereas Boolean logic would be unable to make this inference

## Why Boolean Logic Fails Here
- Boolean logic cannot handle the case where B is true but A is unknown
- In Boolean logic, knowing A → B and B does not allow us to infer A (it could be false and B still true)
- Common sense suggests Werder likely won, but Boolean logic cannot reflect this nuance

## Key Difference
| Feature | Boolean Logic | Bayesian Reasoning |
|---------|----------------|---------------------|
| Values | True/False | Probabilities (0-1) |
| Inference | Deterministic | Probabilistic updates |
| Example | Cannot infer A from B | Updates P(A) when B is observed |

> **Note**: The football example shows how Bayesian reasoning handles uncertainty. While Boolean logic would say 'we cannot determine A', Bayesian reasoning provides a way to update probabilities based on evidence.
