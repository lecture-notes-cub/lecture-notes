# Sample Size vs. Parameter Count and Bayesian Updating

## Key Concepts

### Maximum Likelihood Estimation (MLE) Conditions
- MLE is justified when **n >> d** (sample size much larger than parameter dimension) [00:41:49–00:42:46]
- When **n ≈ d** (sample size comparable to parameter count), MLE leads to overfitting [00:43:19–00:43:49]

### Overfitting in Practice
- **Overfitting occurs** when: `n < d` or `n ≈ d` [00:43:19–00:43:49]
- **Good generalization** occurs when: `n >> d` [00:43:19–00:43:49]
- Example: Early deep neural networks (small parameter count) trained on large datasets showed no overfitting [00:43:50–00:44:19]
- Example: Modern deep neural networks (larger parameter count) show overfitting [00:44:52–00:45:20]

### Bayesian Updating with No Observations
- When **n = 0** (no observations):
  - Posterior = Prior [00:45:58–00:46:28]
  - Posterior distribution = Uniform distribution (or the variable's natural distribution) [00:45:58–00:46:28]
- With **n ≥ 1** (one observation):
  - Posterior updates from prior [00:45:58–00:46:28]
  - Bayesian framework provides a formal way to incorporate observations [00:45:58–00:46:28]

## Why This Matters

### MLE vs. Bayesian
- MLE: Point estimate (classical statistics) [00:40:46–00:41:49]
- Bayesian: Distribution of parameters (probabilistic) [00:40:46–00:41:49]
- Bayesian framework works for **any** number of observations (including zero) [00:45:58–00:46:28]
