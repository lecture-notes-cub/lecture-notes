# Maximum-Likelihood Estimation

## Definition
The maximum-likelihood estimator (MLE) is the value of parameter \(\theta\) that maximizes the likelihood function:

$$\mathcal{L}(\theta) = \prod_{i=1}^{n} p(x_i | \theta)$$

where $x_i$ are independent and identically distributed (i.i.d.) observations from a distribution with unknown parameter $\theta$.

**Source**: [00:21:00–00:21:32]

## Why Log Likelihood is Used

The likelihood function is a product of probabilities, which is difficult to maximize directly due to:

1. **Numerical instability**: Products of small probabilities become extremely small numbers, causing underflow issues in computation.

   **Source**: [00:21:33–00:22:03]

2. **Mathematical convenience**: Taking the logarithm converts the product into a sum (since $\log(ab) = \log a + \log b$), which is easier to maximize using calculus.

   **Source**: [00:21:33–00:22:03]

The log-likelihood function is:

$$\ell(\theta) = \log \mathcal{L}(\theta) = \sum_{i=1}^{n} \log p(x_i | \theta)$$

This sum is easier to work with because:
- It avoids numerical underflow
- The derivative of the log-likelihood is simpler to compute
- Optimization techniques (e.g., gradient descent) are more efficient with sums than products

**Source**: [00:21:33–00:22:03]

## Key Example

For a normal distribution with mean $\mu$ and variance $\sigma^2$, the likelihood function is:

$$\mathcal{L}(\mu, \sigma^2) = \prod_{i=1}^{n} \frac{1}{\sqrt{2\pi \sigma^2}} \exp\left(-\frac{(x_i - \mu)^2}{2\sigma^2}\right)$$

The log-likelihood simplifies to:

$$\ell(\mu, \sigma^2) = -\frac{n}{2} \log(2\pi \sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{n} (x_i - \mu)^2$$

This form makes it straightforward to derive the MLEs for $\mu$ and $\sigma^2$.
