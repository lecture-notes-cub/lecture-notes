# Predicting Unobserved Variables from Joint Probabilistic Models

## Key Concept
To predict an unobserved variable $X$ given an observed variable $Y$ from a joint distribution $P(X, Y, Z)$:

- Compute the conditional distribution $P(X | Y) = \frac{P(X, Y)}{P(Y)}$

## Derivation from Joint Distribution
1. **Numerator**: $P(X, Y) = \int P(X, Y, Z) dZ$ (integrate out $Z$)
2. **Denominator**: $P(Y) = \int P(X, Y, Z) dX dZ$ (integrate out $Z$ and $X$)

## Example
Given a joint distribution over $X$, $Y$, $Z$:
- Observe $Y$ (e.g., $Y = y_0$)
- Predict $X$ using $P(X | Y) = \frac{P(X, Y)}{P(Y)}$
