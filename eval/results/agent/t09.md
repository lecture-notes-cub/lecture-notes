# Small-Sample Limitations of Maximum Likelihood Estimation

## Key Example: Two-Heads Coin

- **Problem Setup**: Estimating the probability of heads in a coin toss using maximum likelihood estimation (MLE).
  - *Source*: [00:28:37–00:29:09]

- **MLE Intuition**: For n coin tosses with k heads, MLE estimates probability of heads as $\hat{p} = \frac{k}{n}$.
  - *Source*: [00:30:25–00:31:05]

- **Two-Heads Coin Scenario**:
  - *Observation*: 2 tosses, both heads.
  - *MLE Estimate*: $\hat{p} = \frac{2}{2} = 1$.
  - *Source*: [00:31:05–00:31:38]

- **Why This Is Problematic**:
  - MLE suggests 100% probability of heads, but common sense says this is unlikely (a coin with two heads is improbable).
  - *Source*: [00:31:38–00:32:11]

- **Small-Sample Issue**:
  - With small n (e.g., n=2), MLE does not satisfy the usual properties (e.g., unbiasedness, consistency).
  - With large n (e.g., n=1000), MLE is a good estimate.
  - *Source*: [00:27:59–00:32:13]

- **Key Takeaway**:
  - MLE can be misleading with small samples, as it may produce estimates that contradict common sense or reality.
  - *Source*: [00:27:59–00:32:13]
