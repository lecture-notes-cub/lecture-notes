# Gamma-Poisson Bayesian Update

**Key Definitions**
- **Poisson Distribution**: $P(X_i | \lambda) = \frac{e^{-\lambda} \lambda^{x_i}}{x_i!}$
- **Gamma Prior**: $p(\lambda) = \frac{\beta^{a} \lambda^{a-1} e^{-\beta \lambda}}{\Gamma(a)}$ (where $a$ is shape, $\beta$ is rate)

**Derivation Steps**
1. **Joint Probability**: $p(X_1, ..., X_n | \lambda) = \prod_{i=1}^n \frac{e^{-\lambda} \lambda^{x_i}}{x_i!}$
2. **Posterior**: $p(\lambda | X_1, ..., X_n) \propto \frac{e^{-n\lambda} \lambda^{\sum x_i}}{\prod x_i!} \cdot \frac{\beta^{a} \lambda^{a-1} e^{-\beta \lambda}}{\Gamma(a)}$
3. **Simplification**: $p(\lambda | X_1, ..., X_n) \propto \lambda^{(a + \sum x_i) - 1} e^{-(n + \beta)\lambda}$
4. **Posterior Distribution**: $p(\lambda | X_1, ..., X_n) \sim \text{Gamma}(a + \sum x_i, \, n + \beta)$

**Key Insight**
- The posterior distribution is a Gamma distribution with updated parameters: shape $a + \sum x_i$ and rate $n + \beta$ (where $n$ is the number of observations)

**Example**
- If we observe $X_1 = 2, X_2 = 3$ with a prior $\text{Gamma}(a=1, \beta=1)$, the posterior is $\text{Gamma}(a=1+5=6, \, \beta=2+1=3)$
