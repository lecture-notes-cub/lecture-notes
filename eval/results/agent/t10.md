# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta.
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem.

## Core Reasoning

The lecture explains that unlike classical (frequentist) maximum likelihood estimation, which produces a point estimate, Bayesian inference yields a posterior distribution:

- Start with a **prior distribution** reflecting initial knowledge about theta
- Apply Bayes' theorem: 
  \[ \text{Posterior} \propto \text{Likelihood} \times \text{Prior} \]
- Result: A full probability distribution over theta, not a single point

## Critical Distinction

| Feature | Frequentist (Maximum Likelihood) | Bayesian |
|---------|-------------------------------|-----------|
| Output | Point estimate (e.g., \hat{\theta}) | Full posterior distribution |
| Basis | Data alone | Prior knowledge + data |
| Interpretation | Probability of data given parameter | Probability of parameter given data |

## Example

The lecture mentions that after observing X1, Xn (independent and identically distributed), the posterior distribution is derived by:

\[ P(\theta | X_1, X_n) \propto \prod_{i=1}^n P(X_i | \theta) \times \text{Prior}(\theta) \]

This results in a distribution rather than a single point estimate.
