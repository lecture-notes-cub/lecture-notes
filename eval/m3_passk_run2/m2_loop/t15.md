# Bayesian Reasoning Extends Boolean Logic

## Key Concept: Bayesian vs. Boolean Logic

In Boolean logic, we have variables that are either true or false. The main rule for logical inference is modus ponens: if A is true and A implies B, then B is true.

However, Bayesian reasoning extends this by allowing us to handle uncertainty and probabilistic relationships. Instead of strict true/false values, Bayesian logic uses probabilities to model how evidence affects our beliefs.

## Football Example

The lecture uses a football (soccer) example to illustrate the difference:

- **A**: Werder Bremen wins the match
- **B**: Football fans are celebrating

**Boolean logic limitation**:
- If A → B (if Werder wins, fans celebrate), and B is true (fans are celebrating), Boolean logic cannot determine if A is true or false. It would be inconsistent with Boolean logic to say that A must be true.

**Bayesian reasoning solution**:
- We can model the joint probability distribution of A and B
- Using Bayes' theorem: P(A|B) = P(B|A) * P(A) / P(B)
- This allows us to update our belief about A (Werder winning) based on evidence B (fans celebrating)

**Key insight**:
- In Boolean logic, we cannot conclude A is true when B is true
- Bayesian reasoning allows us to say that the probability of A (Werder winning) is higher than the prior probability, but not 100% certain

**Probability update**:
- Prior probability of A (Werder winning): 0.1
- After observing B (fans celebrating), posterior probability of A increases

**Why this matters**:
- Bayesian reasoning handles real-world uncertainty where multiple factors can influence outcomes
- It allows for probabilistic conclusions rather than absolute truths
