# Bayesian Parameter Estimation vs. Point Estimates

## Key Definitions

- **Point Estimate**: A single value (e.g., maximum likelihood estimate) that approximates the parameter theta.
- **Bayesian Parameter Estimation**: A distribution over possible values of theta, derived from prior knowledge and observed data using Bayes' theorem.

## Core Reasoning

- **Frequentist Approach**: Uses maximum likelihood estimation (MLE) to find a single point estimate of theta.
- **Bayesian Approach**: Starts with a prior distribution over theta, applies Bayes' theorem to update this prior with observed data, resulting in a posterior distribution.

## Mathematical Formulation

The posterior distribution is calculated as:

$$P(\theta | X_1, X_n) = \frac{P(X_1, X_n | \theta) \cdot P(\theta)}{P(X_1, X_n)}$$

Where:
- $P(X_1, X_n | \theta)$: Likelihood function (product of independent observations)
- $P(\theta)$: Prior distribution
- $P(X_1, X_n)$: Evidence (normalization constant)

## Key Differences

| Feature | Frequentist (MLE) | Bayesian |
|---------|-------------------|-----------|
| Output | Single point estimate | Full distribution |
| Basis | Maximizes likelihood | Combines prior and likelihood |
| Interpretation | Probability of data | Probability of parameter |
