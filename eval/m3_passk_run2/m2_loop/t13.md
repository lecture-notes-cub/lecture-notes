# Sequential Observation Combination in Bayesian Framework

## Key Concept: Sequential Bayesian Updating

The lecture demonstrates how multiple sensors (or 'wisdoms') with different probabilistic models can sequentially update a posterior distribution for estimating an unknown quantity (e.g., animal mass). This process combines observations from different sources while maintaining probabilistic consistency.

## Example: Elephant Mass Estimation

### Sequential Updating Process
1. **First Update**: Tactile observation → posterior distribution on mass (e.g., 'very large animal' or 'snake-like animal')
2. **Second Update**: Acoustic observation → uses posterior from first update as new prior
   - *Citation*: [00:51:26–00:52:06]
3. **Result**: Combined posterior distribution that reflects information from both observations
   - *Citation*: [00:52:43–00:53:21]

### Why This Works
- Bayesian framework allows combining different probabilistic models (e.g., tactile vs. acoustic)
- Each step uses previous posterior as new prior → builds on prior information
- Final posterior becomes sharp around a specific mass estimate
