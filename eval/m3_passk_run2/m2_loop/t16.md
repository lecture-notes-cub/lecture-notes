# Alarm Example Study Notes

## Variables
- **T** (Thief): Binary variable (1 = thief present, 0 = no thief)
- **E** (Earthquake): Binary variable (1 = small earthquake, 0 = no earthquake)
- **R** (Radio message): Binary variable (1 = radio announces earthquake, 0 = no radio message)
- **A** (Alarm): Binary variable (1 = SMS alarm triggered, 0 = no SMS alarm)

> **Note**: The transcript uses 'ARM' but this is a typo for 'Alarm' (SMS message). The speaker clarifies this later.

## Causal Graph

The causal graph is defined as:

```
T → A
E → A
E → R
```

This means:
- Thief (T) causes alarm (A)
- Earthquake (E) causes alarm (A)
- Earthquake (E) causes radio message (R)

> **Source**: [01:05:57–01:06:37] "So I create a causal graph. I try to understand what may cause what. So my alarm system may work only because of either thief or earthquake."

## Assumptions

1. **Independence of T and E**: The speaker states they're independent (no causal relationship between thief and earthquake)
2. **Alarm behavior**:
   - If T=1 (thief), A=1 with 100% certainty (no false alarms from thief)
   - If T=0 and E=1 (earthquake), A=1 with 10% probability (false alarm)
   - If T=0 and E=0, A=0 (no alarm)
3. **Radio message behavior**:
   - If E=0, R=0 (no radio message)
   - If E=1, R=1 with 50% probability (based on speaker's estimation)

> **Source**: [01:07:47–01:08:19] and [01:08:55–01:10:09]

## Conditional Probabilities

| Condition | P(A=1) | P(R=1) |
|-----------|--------|--------|
| T=1, E=1 | 1.0 | ? |
| T=1, E=0 | 1.0 | ? |
| T=0, E=1 | 0.1 | 0.5 |
| T=0, E=0 | 0.0 | 0.0 |

> **Source**: [01:10:10–01:10:52] and [01:08:55–01:09:25]

### Key Probabilities
- P(E=1) = 1/100 (1 small earthquake per 100 days) [01:08:20–01:08:55]
- P(T=1) = 2/10,000 (2 robberies per 10,000 flats per day) [01:08:20–01:08:55]
- P(R=1 | E=1) = 0.5 (radio announces earthquake 50% of the time when earthquake occurs) [01:08:55–01:09:25]
- P(A=1 | T=1, E=0) = 1.0 (thief always triggers alarm) [01:10:10–01:10:52]
- P(A=1 | T=0, E=1) = 0.1 (10% false alarm from earthquake) [01:10:10–01:10:52]

> **Note**: The speaker mentions that the alarm system has 100% reliability for thief detection but 10% false alarm rate when earthquake occurs (as per user guide).
